# Бот мониторинга сервера

Telegram-бот следит за CPU, RAM, swap, дисками, температурой, службами и процессами.
Отвечает на команды и сам присылает алерты, когда что-то превышает порог или падает,
и второе сообщение, когда всё восстановилось. Работает на Linux и Windows.

## Управление
Внизу чата постоянная клавиатура: **Статус**, **Процессы**, **Службы**, **Алерты**, **Настройки**.
Под сообщениями — кнопки: «Обновить» (сообщение обновляется на месте), сортировка процессов
по CPU/RAM, «Заглушить на 1 ч» и «До утра» под алертом.

Меню **Настройки** (всё сохраняется в `settings.json`, старая версия — в `settings.json.bak`):
- пороги CPU / RAM / диска (±5%) и сколько должно держаться превышение (1 / 5 / 15 мин);
- интервал проверки (30 с / 1 мин / 5 мин);
- что отслеживать: включить или выключить службы и контейнеры, «➕» показывает работающие на сервере;
- тихие часы: ночью приходят только критичные алерты (упала служба, контейнер, процесс);
- напоминания о нерешённой проблеме (30 / 60 / 180 мин);
- ежедневная сводка в 09:00 или 20:00;
- сброс к значениям из `config.yaml`.

Команды тоже работают: `/status`, `/procs`, `/mem`, `/services`, `/alerts`, `/settings`,
`/mute 2h` (выключить уведомления), `/unmute`.

## Алерты
- Ресурсы (CPU, RAM, диск, температура): если превышение держится дольше заданного времени.
- Службы, контейнеры Docker, процессы: сразу.
- Перезагрузка сервера, срабатывание OOM killer, «нужна перезагрузка после обновлений».
- Когда проблема исчезла — сообщение «Восстановлено». Пока не исчезла — напоминания.
- Состояние алертов хранится в `state.json`, поэтому после перезапуска бот не повторяет старые алерты.

## Установка
1. Создайте бота у @BotFather и получите токен.
2. На сервере:
   ```
   python -m venv venv
   venv/bin/pip install -r requirements.txt      # Windows: venv\Scripts\pip install -r requirements.txt
   cp config.example.yaml config.yaml            # Windows: copy config.example.yaml config.yaml
   ```
3. Впишите `token` в `config.yaml`, запустите `python bot.py`, отправьте боту `/start`.
   Бот ответит вашим chat_id. Впишите его в `allowed_chats` и перезапустите.
4. Заполните `services`, `processes`, при желании поменяйте пороги.

## Автозапуск
- **Linux:** `deploy/monitor-bot.service` (инструкция внутри файла). Настройки и состояние бот пишет в `/var/lib/monitor_bot`.
- **Windows:** Планировщик заданий, триггер «При запуске компьютера», действие
  `venv\Scripts\pythonw.exe bot.py config.yaml`, рабочая папка = папка бота,
  «Выполнять для всех пользователей». Либо служба через NSSM.
